综合练习中你会发现什么

综合练习让你直接在浏览器中练习 SQL 查询——无需安装数据库。每个查询都在真实的 SQLite 引擎上运行、获得评分，并配有示例解答和讲解。

  • SELECT 与筛选： 选择列、WHERE、DISTINCT、LIKE、IN、BETWEEN。
  • 排序与限制： ORDER BY、LIMIT、OFFSET。
  • 分组与聚合： GROUP BY、HAVING、COUNT、SUM、AVG、MIN、MAX。
  • JOIN： INNER 和 LEFT JOIN、反连接，以及棘手的连接。
  • 高级： 子查询、CASE、窗口函数（ROW_NUMBER、RANK、DENSE_RANK）。
  • 文本与日期： UPPER/LOWER、TRIM、REPLACE、strftime 等等。
  • 面试准备： 数据分析师面试中常见的 SQL 题目，按难度等级划分。

这个练习适合谁

适合任何从零开始学习 SQL 的人、学生，以及为 数据分析师（Data Analyst）面试做准备的求职者。题目从易到难编排，让你能循序渐进。

练习数据库

这个练习运行在一个带 14 张关联表 的数据库上——员工、部门、考勤、订单、订单项、产品、供应商、类别、客户和付款——最多容纳 30,000 条记录。你可以在练习内部查看完整结构和关系图（ERD）。

常见问题

是的。它完全免费使用，无需注册，无需付费。

不需要。SQLite 引擎直接在浏览器中运行（sql.js），所以你完全无需安装就能编写并运行真实的查询。
