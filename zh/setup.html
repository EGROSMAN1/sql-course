📦 第 0 步 —— 准备源文件
从 Google Drive 下载两个 SQL 文件

在打开任何东西之前，确保以下两个文件已从 Google Drive 下载并保存到你的电脑上：

📄
NORTHWIND(4).sql
结构文件——构建空表
📊
northwind-data.sql
数据文件——插入实际数据
⚠️ 必需文件

注意： the northwind-data.sql 文件是最重要的一个。确保你选的是它，而不是名称相似的其他文件。

1
🏗️ 第 1 步 —— 打好基础（结构）
在 MySQL Workbench 中打开结构文件

Open MySQL Workbench.

📂
在顶部菜单中，点击 File 然后选择： Open SQL Script...
🖱️
在打开的对话框中，导航到你保存文件的文件夹。选择第一个文件： NORTHWIND(4).sql
⚡
选择文件后，代码会出现在屏幕上。点击 闪电图标 （位于顶部工具栏）来运行脚本并构建表。

* 注意： 这个文件构建空表。它是数据库的骨架。

✓ Step 1 complete: 表已成功创建。结构现在已经存在，但还是空的。下一步将导入数据。

2
💾 第 2 步 —— 导入数据
把数据文件加载到表中
📂
重复同样的过程： File → Open SQL Script...
🖱️
这次选择第二个文件： northwind-data.sql — 而不是之前的结构文件
⚡
新代码会出现在屏幕上（替换之前的代码）。点击 闪电图标 再次点击，把数据插入你创建的表中。

注意： 这一步可能需要几秒钟——脚本会插入数千行。请等到看到成功消息为止。

✓
✅ 质量检查 —— 验证结果
确保 Northwind 出现在 Schemas 列表中

流程完成后，下面是确认一切正常的方法：

👈
前往左侧的 Schemas 面板，然后点击 Refresh 按钮。
🔍
你现在会看到 Northwind 出现在列表中，以粗体显示。这意味着数据库已经就绪！

🎉 恭喜！ 你的环境已经准备好了。现在你可以开始在 Northwind 数据库上编写 SQL 查询了。

Click Northwind 把它设为当前数据库，就可以开始了。

常见问题： 如果 Northwind 没有出现——确保你点击了 Refresh，并且运行了 两个 文件（NORTHWIND(4).sql 和 northwind-data.sql）。

快速测试 —— 你的第一个查询
🚀
检查是否正常——运行你的第一个查询
如果你得到了结果——你成功了！

在 Workbench 中打开一个新的查询编辑器（Query Editor）并运行：

USE Northwind;
SELECT * FROM customers LIMIT 5;

如果你得到一张包含 5 位客户的表——说明数据库运行得很完美！🎉
