מה תמצאו בתרגול המקיף

התרגול המקיף מאפשר לתרגל שאילתות SQL בעברית ישירות בדפדפן — בלי להתקין מסד נתונים. כל שאילתה רצה על מנוע SQLite אמיתי, מקבלת ציון, ומלווה בפתרון לדוגמה ובהסבר.

  • SELECT וסינון: שליפת עמודות, WHERE, DISTINCT, LIKE, IN, BETWEEN.
  • מיון ומגבלה: ORDER BY, LIMIT, OFFSET.
  • קיבוץ ואגרגציה: GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX.
  • JOIN: INNER ו-LEFT JOIN, anti-join וצירופים מתעתעים.
  • מתקדם: תת-שאילתות, CASE, פונקציות חלון (ROW_NUMBER, RANK, DENSE_RANK).
  • טקסט ותאריך: UPPER/LOWER, TRIM, REPLACE, strftime ועוד.
  • הכנה לראיון: שאלות SQL נפוצות בראיונות לאנליסט נתונים, לפי רמת קושי.

למי התרגול מתאים

לכל מי שלומד SQL מאפס, לסטודנטים, ולמחפשי עבודה שמתכוננים לראיון אנליסט נתונים (Data Analyst). השאלות מסודרות מהקל לקשה, כך שאפשר להתקדם בהדרגה.

מסד הנתונים לתרגול

התרגול מתבצע על מסד נתונים עם 14 טבלאות מקושרות — עובדים, מחלקות, נוכחות, הזמנות, פריטי הזמנה, מוצרים, ספקים, קטגוריות, לקוחות ותשלומים — ובו עד 30,000 רשומות. אפשר לצפות במבנה המלא ובתרשים הקשרים (ERD) מתוך התרגול.

שאלות נפוצות

האם התרגול בחינם?

כן. השימוש חופשי לחלוטין, ללא הרשמה וללא תשלום.

האם צריך להתקין תוכנה או מסד נתונים?

לא. מנוע SQLite רץ ישירות בדפדפן (sql.js), כך שאפשר לכתוב ולהריץ שאילתות אמיתיות בלי שום התקנה.

אילו נושאי SQL נכללים בתרגול?

SELECT, סינון בעזרת WHERE, מיון ומגבלה, GROUP BY ואגרגציות, סוגי JOIN, תת-שאילתות, פונקציות חלון כמו ROW_NUMBER ו-RANK, ופונקציות טקסט ותאריך.

האם התרגול מתאים להכנה לראיון עבודה לאנליסט נתונים?

כן. יש קטגוריות ייעודיות של שאלות ראיון SQL נפוצות, מסודרות לפי רמת קושי.
